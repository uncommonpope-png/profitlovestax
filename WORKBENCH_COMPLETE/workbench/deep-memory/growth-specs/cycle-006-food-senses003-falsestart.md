The first launch of this pass (19:30 CDT) was started **without the cycle env loaded** (`workbench.env` not sourced — the mistake is the operator's, mine). `vault_credentials` therefore resolved no provider keys and **no seat could answer**: all five items it reached (q10–q14) were fetched and source-digested with **no absorption** — the circuit's whole point — and their queue entries were marked read with source outcomes only. One further artifact: with the env absent, the `SESHAT_LOCAL_MODEL=off` kill-switch never reached the digestion judge, so the **untrained local seat judged the in-band addyosmani source and quarantined it** (substance 0, "fluent but empty" — the boilerplate verdict shape the Local Mind proof recorded against this stock 1.5B judge, fixtures 1/3).

The run was **killed after q14** (q15–q17 untouched). The partial record is preserved verbatim at `/tmp/senses003/results.false-start.json`. The pass was then **re-run whole** with the env sourced — the same eight items, the same circuit — and the re-run superseded the false start everywhere: digestion pages carry the same date+title file names and were overwritten by the true pass; the queue entries were re-marked with their true outcomes; the digestion log keeps both events, as an append-only witness should. **On the true pass the kill-switch held: the local seat never judged** (see §3 per-item judge notes).
