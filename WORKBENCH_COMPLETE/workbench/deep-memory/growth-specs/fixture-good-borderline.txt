BM25 ranking, in brief. BM25 scores a document for a query by summing per-term weights: for each query term, IDF multiplied by a saturated term-frequency factor. The saturation uses k1, usually between 1.2 and 2.0; the length-normalization parameter b defaults to 0.75, where 0 disables normalization and 1 applies it fully. IDF is computed as ln(1 + (N - n + 0.5) / (n + 0.5)), with N the number of documents and n the number containing the term. Robertson and Walker published the formula's probabilistic basis in 1994, building on work at City University London. Because the TF factor saturates, repeating a term ten times never scores ten times higher, which is why BM25 resists keyword stuffing better than raw TF-IDF.
